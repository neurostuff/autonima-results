# E0: token reductions, and the noise floor

The test workspace is `~/repos/cbma-workspace-e0`. It is a copy of the first
cbma-skills run, with 200 abstracts, 20 full texts, 20 extractions and 20 selections
held out and re-judged. The held-out lists are in `held_out.json` there. The results,
and how they were computed, are in experiments/cbma-skills/PLAN.md, "E0 result".
`audit.json` is the transcript audit. It includes the pre-E0 smoke-test judges, which
show up as medium-effort abstract judges.
