Inclusion / Exclusion Criteria

Global Criteria

Inclusion

  • GLOBAL_I1: Voxelwise task evidence- The analysis must be a group-level, univariate task-evoked voxelwise map (typically whole-brain; small-volume-corrected maps are acceptable).
  • GLOBAL_I2: Task-based problem solving- The contrast must reflect active problem solving, reasoning, or goal-directed cognitive processing (e.g., rule application, planning, relational reasoning, symbolic manipulation).
  • GLOBAL_I3: Valid comparator condition- The analysis/contrast must compare problem solving against an appropriate baseline or control condition (e.g., rest, fixation, perceptual control, low-level baseline, or simpler task condition).
  • GLOBAL_I4: Domain generality- Analyses may come from any representational domain (e.g., mathematical, verbal, visuospatial, logical), provided they isolate problem solving processes.
  • GLOBAL_I5: Stereotactic reporting- Coordinates must be reported in standard stereotactic space (MNI or Talairach).

Exclusion

  • GLOBAL_E1: ROI-only analyses without whole-brain voxelwise results or stereotactic coordinates.
  • GLOBAL_E2: Connectivity analyses- Seed-based connectivity, effective connectivity, or resting-state analyses.
  • GLOBAL_E3: Non-task or passive paradigms- Passive viewing, simple perception, or tasks not requiring active problem solving or reasoning.
  • GLOBAL_E4: Motor or response-only contrasts that do not isolate cognitive problem solving processes.
  • GLOBAL_E5: Clinical or between-group contrasts that do not isolate a within-task problem solving effect (unless a valid problem solving contrast is reported separately).

Annotation-Specific Criteria (mathematical_problem_solving)

Inclusion

  • MATHEMATICAL_PROBLEM_SOLVING_I1: Analyses must involve active mathematical reasoning or computation.
  • MATHEMATICAL_PROBLEM_SOLVING_I2: Contrast must isolate mathematical problem solving versus a valid control.

Exclusion

  • MATHEMATICAL_PROBLEM_SOLVING_E1: Exclude simple number perception or rote calculation without problem solving demands.
