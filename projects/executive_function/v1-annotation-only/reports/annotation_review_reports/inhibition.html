Inclusion / Exclusion Criteria

Global Criteria

Inclusion

  • GLOBAL_I1: The analysis must be a within-group, group-level, whole-brain (voxelwise) task activation contrast
  • GLOBAL_I2: The task of interest must be contrasted against an ACTIVE control task
  • GLOBAL_I3: The task must require an overt behavioral response (e.g., a button press)
  • GLOBAL_I4: Participants must be healthy adults aged 18-60

Exclusion

  • GLOBAL_E1: Contrasts against rest, fixation, or a passive baseline rather than an active control task
  • GLOBAL_E2: Between-group contrasts (e.g., patients vs controls, or any comparison of two participant groups) rather than within-group task activation
  • GLOBAL_E3: Region-of-interest (ROI) or small-volume-corrected (SVC) analyses
  • GLOBAL_E4: Connectivity or resting-state analyses (functional connectivity, PPI, DCM, ICA)
  • GLOBAL_E5: Tasks that do not require an overt behavioral response (e.g., passive viewing or listening)
  • GLOBAL_E6: Analyses that do not isolate a specific executive function process

Annotation-Specific Criteria (inhibition)

Inclusion

  • INHIBITION_I1: Task is an INHIBITION paradigm: Go/No-Go, Stroop, Flanker, Simon task, or antisaccade
  • INHIBITION_I2: The contrast isolates the inhibitory demand against an active control (e.g., No-Go > Go, incongruent > congruent, antisaccade > prosaccade)

Exclusion

  • INHIBITION_E1: The contrast being annotated isolates a different executive function domain (e.g., n-back, Sternberg, task switching, Tower tasks, word generation, oddball). Other tasks reported elsewhere in the same paper are irrelevant: judge only the contrast described by this analysis.
