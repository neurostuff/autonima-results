Fulltext Reasoning: This is an fMRI task study of verbal working memory (mPASAT) that reports within-group contrasts and voxel coordinates, but the statistical analyses are restricted to a predetermined set of ROIs (Brodmann areas) rather than providing a whole-brain, group-level voxelwise activation map. Therefore it fails the requirement for whole-brain (or non-ROI-restricted) voxelwise task-evoked results (I7) and is excluded under exclusion criterion E3 (ROI-only analyses with no voxelwise whole-brain results). Inclusion criteria met: I5 (task-based fMRI), I6 (working memory executive domain), I8 (within-group task contrasts reported), I9 (participants/groups acceptable), I10 (results reported with coordinates/tables).
