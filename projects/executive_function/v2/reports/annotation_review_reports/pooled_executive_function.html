Global Criteria

Inclusion

  • GLOBAL_I1: Whole-brain evidence- The analysis must be from a group-level, univariate whole-brain (voxelwise) task-evoked statistical map (e.g., main effect or within-group contrast).   • GLOBAL_I2: Contrast or analysis must be relevant to executive function or cognitive control task performance.

Exclusion

  • GLOBAL_E1: Region-of-interest (ROI) analyses
  • GLOBAL_E2: Seed-based connectivity, effective connectivity (e.g., PPI, DCM), or resting-state analyses (e.g., ICA, PLE, Hurst exponents)
  • GLOBAL_E3: Analyses not involving executive function or cognitive control processes
