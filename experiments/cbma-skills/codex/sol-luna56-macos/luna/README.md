# Sol / Luna 5.6 reviews

Projects: cue_reactivity, emotion_regulation_2022, problem_solving, vbm_of_ptsd and
vbm_of_substance_use. All judges use gpt-5.6-luna at the configured stage efforts;
orchestration uses gpt-6.1-sol/medium. Each review has fresh ledgers and local
scientific skill copies. See ../README.md for the article-copy prerequisite.

From the enclosing bundle, run ./copy_articles.sh /path/to/old/bundle once and
sign in with bash login.sh if needed. Then ./run_all_luna.sh runs all five
sequentially, ./luna/run_review.sh PROJECT runs one headlessly, and
./luna/run_codex.sh PROJECT opens an interactive session. The default prompt
completes all stages without a pilot or approval pause; required audits remain.
Missing inputs are documented while usable studies continue. Genuine scientific
or persistent account/tool blockers remain reportable. Do not launch two workers
for the same review. This folder requires the enclosing bundled runtime.
